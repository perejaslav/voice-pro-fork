# Voice-Pro-Fork: Ультимативный ИИ-инструмент для дубляжа и перевода видео

**Voice-Pro-Fork** — это расширенная версия оригинального проекта Voice-Pro, превращающая его в полноценную студию автоматизированного дубляжа. Этот форк добавляет критически важные функции для профессиональной и массовой локализации контента.

![ABUS-logo](docs/images/ABUS-logo.jpg)

---

## 🚀 Что нового в этом форке?

Мы существенно доработали проект, добавив функции, которые ранее были лишь «заглушками» или отсутствовали:

1.  **Пакетный дубляж (Batch Dubbing):**
    *   Теперь вы можете озвучивать целые папки с видео одним нажатием.
    *   Автоматический поиск переведенных субтитров (SRT) для каждого файла.
    *   Интеллектуальное микширование новой озвучки с фоновой музыкой (Instrumental).

2.  **Интеграция Lip-Sync (Синхронизация губ):**
    *   Добавлена поддержка технологии **Wav2Lip**.
    *   Персонажи на видео теперь открывают рот в точном соответствии с новой аудиодорожкой.
    *   Функция доступна как для одиночных видео, так и в пакетном режиме.

3.  **Оптимизация пайплайнов:**
    *   Улучшена работа с движками синтеза речи: Edge-TTS, F5-TTS, CosyVoice и Kokoro.

## 🛠 Инструкция по установке (для новичков)

Эта инструкция поможет вам запустить проект на Windows «с нуля».

### Шаг 1: Подготовка
Убедитесь, что на вашем компьютере установлены:
1.  **Python 3.10** (обязательно эта версия). [Скачать здесь](https://www.python.org/downloads/windows/). При установке поставьте галочку **"Add Python to PATH"**.
2.  **Git.** [Скачать здесь](https://git-scm.com/downloads).
3.  **FFmpeg.** Это важно для работы с видео. 
    *   Скачайте [ffmpeg-master-latest-win64-gpl.zip](https://github.com/BtbN/FFmpeg-Builds/releases).
    *   Распакуйте и добавьте путь к папке `bin` в системные переменные PATH.

### Шаг 2: Клонирование проекта
Откройте терминал (или командную строку) и введите:
```bash
git clone https://github.com/perejaslav/voice-pro-fork.git
cd voice-pro-fork
```

### Шаг 3: Установка зависимостей
Запустите файл для автоматической настройки. Он создаст виртуальное окружение и установит все библиотеки.

*   Если у вас видеокарта **NVIDIA** (рекомендуется):
    Запустите `configure.bat` (просто дважды кликните по нему).
*   Если у вас нет видеокарты NVIDIA (только процессор):
    Установка может занять больше времени и некоторые функции (например, Lip-Sync) будут работать очень медленно.

### Шаг 4: Модели для Lip-Sync (Важно!)
Для работы синхронизации губ вам нужно вручную скачать две модели и положить их в папку `model/lipsync/`:
1.  [wav2lip_gan.pth](https://github.com/perejaslav/voice-pro-fork/releases/download/v1.0.0/wav2lip_gan.pth) (пример ссылки, замените на реальную при наличии)
2.  [s3fd.pth](https://github.com/perejaslav/voice-pro-fork/releases/download/v1.0.0/s3fd.pth)

*Примечание: Если папки `model/lipsync` нет, создайте её.*

### Шаг 5: Запуск
Просто запустите файл:
```bash
start.bat
```
После запуска в консоли появится адрес вида `http://127.0.0.1:7860`. Скопируйте его и откройте в браузере.

## 📖 Как пользоваться

1.  **Dubbing Studio:** Загрузите видео или вставьте ссылку на YouTube. Нажмите "Transcribe", затем "Translate", выберите голос и нажмите "Synthesis". Не забудьте поставить галочку **"Enable Lip-Sync"** для синхронизации губ.
2.  **Batch TTS:** Выберите папку с видеофайлами. Проведите пакетное распознавание и перевод. Затем выберите голос и запустите массовый дубляж.

---

## ⚠️ Системные требования
*   **ОС:** Windows 10/11 или Linux.
*   **GPU:** NVIDIA с 8ГБ+ VRAM (для комфортной работы Lip-Sync и F5-TTS).
*   **Место на диске:** Около 10-15 ГБ для моделей и временных файлов.
